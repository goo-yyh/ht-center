# 海天集团供应链资源湖（SCROS）需求功能大纲

## 1. 项目背景与痛点

### 1.1 外部环境

- 全球供应链重构: 从成本最优转向区域化、近岸化、多区域、多供应商网络
- 地缘政治与贸易环境不确定: 地区冲突、贸易制裁、关税壁垒、国际物流受阻常态化
- 原材料价格和供需波动加剧: 传统议价与成本核算难以及时响应市场变化
- AI 驱动供应链效率革命: 智能预测、自动匹配、库存优化、风险预警、自动化决策成为趋势
- 一流企业对标启示: 端到端流程集成、全球协同、供应网络主动设计、数据驱动生态协同

### 1.2 内部问题

- 供应商资源分散: 各产业、生产基地资源不互通，缺少集团统一视图
- 重复寻源严重: 类似物料重复找供应商，浪费时间、人力和沟通成本
- 决策依赖经验: 准入、核价、份额、风险判断缺少统一量化模型
- 风险预警不足: 财务、合规、舆情、地缘、原材料等风险缺少实时监控
- 柔性替代能力不足: 关键物料备用梯队和快速切换机制不完善
- 现有系统偏执行: SRM 和数据库偏信息记录，缺少价值发现、智能决策和资源统筹

### 1.3 建设必要性

- 从经验驱动采购升级为数据驱动采购，再升级为 AI 驱动采购
- 形成集团级、跨部门、可持续演进的供应链战略操作系统
- 将供应链从成本中心转变为价值创造中心

## 2. 项目目标

### 2.1 总体目标

- 建设 SCROS 供应链资源操作系统
- 形成一湖、两池、三平台、六大 AI Agent 的能力架构
- 整合供应商、价格、质量、交付、产能、风险、工艺、行业、海外资源等全域数据
- 实现供应链资源共享、智能决策、风险预警、柔性调度和生态协同

### 2.2 核心解决问题

- 资源分散: 建立唯一供应商 ID 和集团统一资源视图
- 重复寻源: 通过资源池和资源开发平台复用优质供应商
- 经验决策: 用画像、核价、份额、风险模型支撑量化决策
- 风险滞后: 建立识别、评估、应对、监控审查闭环
- 柔性不足: 建立关键物料柔性供应池和动态备用梯队
- 生态协同不足: 向核心供应商开放非敏感协同能力

### 2.3 预期结果

- 采购效率提升: 缩短寻源周期与沟通周期
- 采购成本降低: 通过核价、份额、竞争机制和资源复用降本
- 库存成本优化: 通过产能可视、柔性调度和协同降低库存占用
- 供应链韧性增强: 提升对断供、价格波动、质量异常、交付异常的响应能力
- 管理透明可追溯: 决策过程有数据、有模型、有审计记录
- 组织能力沉淀: 将采购经验、评估逻辑、核价规则和风险策略系统化

## 3. 总体功能架构

### 3.1 一湖: 供应链资源湖

- 集团统一数据底座
- 统一供应商主数据和唯一供应商 ID
- 沉淀价格、质量、交付、产能、风险、工艺、行业等数据资产

### 3.2 两池: 统筹资源池与柔性供应池

- 统筹资源池: 集团供应商超市，支持共享、分类、调用、复用
- 柔性供应池: 关键物料备用梯队，支持风险触发和快速切换

### 3.3 三平台: 能力构建核心引擎

- 资源开发平台: AI 寻源、产业集群地图、供应商准入认证
- 数据治理平台: 数据集成、清洗、标准化、主数据管理、质量监控
- 智能决策平台: 模型、算法、评分、核价、份额、风险、Agent 编排

### 3.4 六大 AI Agent

- 寻源 Agent
- 核价 Agent
- 画像 Agent
- 份额 Agent
- 风险 Agent
- 调度 Agent

### 3.5 业务闭环

- 数据采集
- 数据治理
- 模型分析
- 策略输出
- 人工确认
- 业务执行
- 结果回写

## 8. 核心业务能力

### 8.1 供应商 360 度画像

- 能力画像: 技术研发、产能规模、设备能力、扩产能力、成本结构
- 成本画像: 价格水平、全生命周期成本、价格稳定性、降本潜力
- 质量画像: 质量绩效、质量体系、来料合格率、异常处理、售后质量
- 交付画像: 准时交付率、订单完成率、交付周期、响应速度、服务能力
- 风险画像: 财务稳健性、运营可持续性、合规、诉讼、舆情
- 战略协同画像: 合作表现、战略契合度、协同意愿、创新能力、长期价值
- 画像输出
  - 综合评分
  - 分项评分
  - 优势短板
  - 风险和改进建议
  - 历史趋势对比

### 8.2 风险管理体系

- 风险识别: 多渠道信息自动收集和甄别

- 风险应对: 整改、份额调整、启动备选、提前备货、价格锁定、合同调整
- 监控审查: 跟踪处置结果，复盘并优化规则
- 重点风险
  - 单一来源风险
  - 供应商财务风险
  - 地缘政治风险
  - 战争与疫情风险
  - 关键原材料风险

### 8.3 动态份额模型

- 综合评分公式

  - 战略协同得分 * 权重

- 季度动态重算
- 授权阈值内人工调整
- 调整原因和审批审计
- 优质供应商正向激励

- 资质维护协同

## 12. 商业模式与运营机制

### 12.1 商业模式定位

- 集团内部供应链能力平台
- 价值创造系统
- 通过平台建设、数据资产、智能决策和供应商生态协同形成价值闭环

### 12.2 运行机制

- 集团统一建设，业务单元共享调用
- 供应商进入资源池，按绩效获得机会
- 动态份额模型引入市场化竞争
- 柔性供应池形成供应链保险机制
- 供应商生态协同提升长期竞争力

### 12.3 价值创造方式

- 降低采购成本
- 降低库存成本
- 提升采购人效
- 降低供应风险损失
- 提升管理透明度
- 沉淀组织能力

### 12.4 成本投入

- 平台建设成本
- 数据治理成本
- 外部数据成本
- AI 模型建设成本
- 组织变革成本
- 运营维护成本

### 12.5 收益衡量

- 成本类: 节约金额、节约率、核价节约、异常报价识别
- 效率类: 寻源周期、采购周期、重复寻源减少、自动报告生成
- 资源类: 主数据入库率、资源共享率、调用次数、跨基地复用率
- 风险类: 单一来源下降、预警准确率、处置闭环率、替代覆盖率
- 绩效类: 准时交付率、质量合格率、绩效提升率、自动评估率
- 生态类: 协同覆盖率、整改闭环率、供应商满意度、流程线上化率
